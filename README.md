# Central Amigxs — versão web

Build web do app **Central Amigxs**, publicado para quem não consegue instalar o APK
(principalmente iPhone). Mesma sala, mesmo servidor: dá para jogar junto com quem está
no aplicativo.

Jogue em: https://jvmorales01.github.io/central-amigxs-web/

O código-fonte do app é privado; aqui fica apenas o bundle compilado.
